# GameHub circular

Plataforma comunitaria para comprar, vender, intercambiar y donar videojuegos físicos.
Python + POO + SQL Server + tkinter.

## Cómo ejecutarlo
1. En VS Code (extensión SQL Server, conexión a localhost) abrir basededatos/gamehub.sql,
   seleccionar todo (Ctrl + A) y ejecutar (▶). Debe existir antes una base llamada GameHub.
2. pip install pyodbc
3. python basededatos/conexion.py   -> "Conexión exitosa con SQL Server"
4. python main.py
